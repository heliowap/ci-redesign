# Contract: Immutable Release Bundle Schema

This contract defines the structure and authentication mechanisms of release bundles admitted for production deployment.

```json
{
  "$schema": "https://json-schema.org/draft/2020-12/schema",
  "title": "ReleaseBundle",
  "type": "object",
  "required": [
    "schema_version",
    "bundle_id",
    "created_at",
    "source_commit_sha",
    "source_tree_sha",
    "policy_version",
    "platform_digests",
    "configuration_identities",
    "migration_manifest_identity",
    "global_verification_obligations",
    "provenance"
  ],
  "properties": {
    "schema_version": { "type": "string", "const": "1.0.0" },
    "bundle_id": { "type": "string" },
    "created_at": { "type": "string", "format": "date-time" },
    "source_commit_sha": { "type": "string", "pattern": "^[0-9a-f]{40}$" },
    "source_tree_sha": { "type": "string", "pattern": "^[0-9a-f]{40}$" },
    "policy_version": { "type": "string" },
    "platform_digests": {
      "type": "object",
      "description": "Mapping of service names to platform digests",
      "additionalProperties": {
        "type": "object",
        "required": ["linux/amd64", "linux/arm64"],
        "properties": {
          "linux/amd64": { "type": "string", "pattern": "^[^\\s@]+@sha256:[0-9a-f]{64}$" },
          "linux/arm64": { "type": "string", "pattern": "^[^\\s@]+@sha256:[0-9a-f]{64}$" }
        }
      }
    },
    "configuration_identities": {
      "type": "object",
      "required": ["compose_files", "config_sha256"]
    },
    "migration_manifest_identity": {
      "type": "object",
      "required": ["migration_roots", "manifest_sha256"]
    },
    "provenance": {
      "type": "object",
      "required": [
        "builder_id",
        "app_id",
        "workflow",
        "run_id",
        "run_attempt",
        "security_isolation"
      ],
      "properties": {
        "builder_id": { "type": "string" },
        "app_id": { "type": "integer" },
        "security_isolation": {
          "type": "object",
          "required": [
            "candidate_code_isolated",
            "authorizes_deployment",
            "authorizes_migration"
          ]
        }
      }
    }
  }
}
```

## Security & Authentication Contract

### 1. Detached Publisher Attestation (`<bundle>.json.attestation`)
The bundle is cryptographically authenticated by the trusted publisher workflow before distribution. The attestation is generated by computing an HMAC-SHA256 (or Sigstore signature) over canonicalized bundle JSON (excluding dynamic admission receipt fields).
- Shared key environment variable: `RELEASE_BUNDLE_ATTESTATION_KEY`.
- The CLI verifies the attestation and fails closed if missing or invalid.

### 2. Image Subject Allowlist
Platform digests must reside under an approved repository namespace (default prefix: `ghcr.io/{org}/` or configurable via `RELEASE_BUNDLE_ALLOWED_IMAGE_PREFIXES`). Any reference to third-party or arbitrary registries rejects admission immediately.

### 3. Admission Receipt
On successful validation against the deployment host and target commit, `ci_release_bundle.py admit` writes an immutable admission receipt containing the verified bundle ID, platform digest mapping, and timestamp, authorizing `sync-main.sh` to pull images strictly by digest.
